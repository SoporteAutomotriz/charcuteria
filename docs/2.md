1. Tabla cotizaciones — sin política RLS para anon

Corregido: La tabla cotizaciones no tiene ninguna política de RLS para el rol anon. El cliente nunca lee Supabase directamente.

- El cliente obtiene su cotización a través de un endpoint del servidor (GET /api/cotizaciones/:token o similar).
- Ese endpoint usa service_role de Supabase para buscar la cotización por token y devolver solo los campos que el cliente debe ver.
- El rol anon no tiene política de SELECT ni de INSERT en

---

2. Tabla zonas_transporte — sin lectura directa para anon

Corregido: zonas_transporte no tiene política de lectura p

- El configurador del cliente pide las zonas y el estimadodel servidor.
- El servidor usa service_role (o el rol autenticado del personal) para leer zonas_transporte y calcular el estimado.
- El rol anon no puede leer zonas_transporte directamente.
